# KYOCERA AVX W3A 0612 4-element capacitor-array library

`C_Array_4x0612` contains four independent capacitors: 1–8, 2–7, 3–6, and 4–5. This follows the standard 8-pad convex array pin ordering used by the referenced CP201-style schematic symbol.

The footprint is a renamed copy of KiCad's KLC-style `R_Array_Convex_4x0612`, which matches the AVX W3A 0612 array's 1.60 x 3.20 mm body and 8-pad 4-element topology. The AVX datasheet specifies the package and recommended pad layout. No exact stock 3D model is installed, so no model is attached rather than using an inaccurate resistor model.
