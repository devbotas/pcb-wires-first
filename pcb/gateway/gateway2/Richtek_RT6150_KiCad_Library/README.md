# Richtek RT6150AGQW KiCad library

This library uses the adjustable `RT6150AGQW` in Richtek's W-type WDFN-10L 3 x 3 mm package. Pinout and dimensions are taken from Richtek RT6150A/B datasheet DS6150AB-06, pages 2 and 12. The exposed pad is pin 11 and must connect to GND.

The footprint is KiCad's stock `WDFN-10-1EP_3x3mm_P0.5mm_EP1.8x2.5mm` land pattern. The copied STEP model is the closest stock 3 x 3 mm / 0.5 mm-pitch DFN model; the exposed-pad difference is internal and not visible in 3D.
