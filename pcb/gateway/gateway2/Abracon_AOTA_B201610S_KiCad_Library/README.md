# Abracon AOTA-B201610S local footprint library

`L_0806_2016Metric.kicad_mod` is a 0806 / 2016 Metric footprint based on the
Abracon AOTA-B201610S recommended land pattern. It supersedes the smaller,
generic KiCad `L_0805_2012Metric` footprint for this 2.0 x 1.6 mm series.

Pads are 1.0 x 1.6 mm, with a 1.0 mm pad-to-pad gap (3.0 mm copper span), per
the manufacturer drawing. This footprint intentionally includes no generic 3D
model: the available KiCad 201610 models are manufacturer-specific and their
mechanical detail is not verified for this part.

Datasheet: <https://abracon.com/datasheets/AOTA-B201610S.pdf>
